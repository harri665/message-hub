# message-hub

Self-hosted web app that syncs iMessage, SMS and WhatsApp from my iPhone into one continuous inbox I can read and reply to from any browser.

- iMessage/SMS come through a macOS VM running Messages.app and BlueBubbles Server.
- WhatsApp comes through a linked-device connector (whatsmeow).
- Everything else runs as a Docker stack on TrueNAS.

See [PLAN.md](PLAN.md) for the full plan.
